## 先分清 CMIN2 和 CMI，这两个词经常被混用

## 买之前值得花五分钟做的三件事

**跑一遍路由测试。** DMIT 提供 Looking Glass 工具，可以直接对机器发起 traceroute。重点看回程落地是不是 58807（CMIN2）或者 9929，以及全程跳数有没有异常绕行。别人的测评代表不了你所在城市的运营商出口。

**在晚高峰测。** 晚上 8 点到 11 点是移动国际出口压力最大的时段。用官方测试 IP 在这个时间段 ping 和 tracert，得到的延迟和丢包才是你真实的使用体验。凌晨测出来的数据没有参考价值。

**确认平台代号和库存。** 同一个 EB 系列下面挂着 AS3、AN4、AN5 不同平台，价格和配置都会变。DMIT 的库存变化很快，特价机型尤其如此，页面显示有货就直接下单，犹豫一晚可能就没了。

支付方面，支付宝、PayPal 和信用卡都可以，对国内用户来说流程上没什么障碍。
